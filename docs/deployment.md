# Deployment & Synchronization Guide

This guide explains how to deploy the Aurumchain smart contracts using Solana Playground (PG) and synchronize the project's web3 library.

## 1. Program Deployment (Solana PG)

Each program follows a modular architecture and should be deployed individually in Solana PG.

### Deployment Order
1.  **Project Registry**: The central source of truth for all projects.
2.  **Compliance & Transfer**: Handles KYC and funding (depends on Registry ID).
3.  **Allocation & Distribution**: Handles profit sharing (depends on Registry ID).

### Steps in Solana PG:
1.  Create a folder for the program (e.g., `allocation_distribution`).
2.  Copy the `src/` folder contents from the local project.
3.  Ensure the `declare_id!` in `lib.rs` matches the address generated by Solana PG.
4.  Click **Build** -> **Deploy**.
5.  Download the generated `idl.json` and save it to your local project at `programs/[program_name]/src/idl.json`.

---

## 2. Local Synchronization

Once the programs are deployed and IDLs are downloaded, you must sync the local project so the frontend and backend can interact with the new addresses.

### Step A: Update Program IDs
Update [lib/web3/config/programs.ts](file:///c:/Rupom/Projects/AURUMCHAIN/lib/web3/config/programs.ts) with the new PublicKeys generated by Solana PG.

### Step B: Sync IDLs
Run the following command to move the IDLs into the centralized web3 folder:
```bash
npm run sync-idl
```
*   **Source**: `programs/[name]/src/idl.json`
*   **Destination**: `lib/web3/idl/[name].json`

### Step C: Patch IDLs (If Required)
If the IDL requires specific modifications (e.g., handling complex enums or shadow structs), run:
```bash
npm run patch-idl:distribution
```

## Technical Maintenance
*   **Adding New Logic**: When adding new instructions, always update the `logic/mod.rs` using the `pub mod name; pub use name::*;` pattern to maintain compatibility with the `sync-idl` scripts.
*   **Shadow Structs**: If the `ProjectAccount` in the Registry changes, the `ShadowProjectAccount` in the Distribution program must be updated manually to match the byte alignment.
